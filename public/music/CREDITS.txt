Music credits for The World Tiki Atlas (tiki.place)
===================================================

Both loops play one original tune over the same chords, 48 seconds long. Composition, arrangement
and all note data were written for this project (assets/music/v2/sketches.py, sketch "exomix").

SPACE loop (/music/space.m4a), heard when the map is zoomed out
  Synthesised in code: pad, sub bass, sparkles, noise wash and swells, hall reverb.
  Sampled: the instruments listed under 1 and the wind chimes listed under 2.

ALOHA loop (/music/aloha.m4a), heard when the map is zoomed in
  Sampled: the instruments listed under 1 and the percussion listed under 2.
  Room reverb: synthesised impulse response (image-source early reflections + noise tail), no samples.

  1. Fluid (R3) General MIDI SoundFont, "FluidR3_GM.sf2", version 3.1
     Copyright (c) 2000-2002, 2008 Frank Wen <getfrank@gmail.com>
     License: MIT (see the full notice below, reproduced as the license requires)
     Source package: fluid-soundfont_3.1.orig.tar.gz
     Rendered offline with FluidSynth (LGPL-2.1 library; used as a tool, not redistributed)
     Presets used in the space loop (bank 0):
       program 8 "Celesta"            theme, first half
       program 60 "French Horn"       line under the theme, then the theme in the second half
       program 40 "Violin"            theme, second half
       program 9 "Glockenspiel"       theme an octave up, second half
       program 42 "Cello"             line under the theme, second half
       program 48 "String Ensemble 1" chords
       program 52 "Choir Aahs"        chords
       program 46 "Orchestral Harp"   arpeggios
     Presets used in the aloha loop (bank 0):
       program 11 "Vibraphone"        theme
       program 12 "Marimba"           theme an octave down in the second half, and the replies
       program 73 "Flute"             slow line in the second half
       program 0 "Grand Piano"        bossa comping
       program 4 "Electric Piano 1"   held chords
       program 32 "Acoustic Bass"     bass
       drum channel, "Standard" kit   closed hi-hat, ride, side stick, kick, toms
